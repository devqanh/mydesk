# Hướng dẫn tải và cài đặt MyDesk

Toàn bộ quá trình mất khoảng **1 phút**. MyDesk miễn phí, tự cập nhật và không cần công cụ hỗ trợ nào khác.

---

## 1. Yêu cầu hệ thống

| | Tối thiểu |
| --- | --- |
| **Windows** | Windows 10 hoặc 11, 64-bit |
| **macOS** | macOS 11 Big Sur trở lên |
| **RAM** | 4 GB (khuyến nghị 8 GB) |
| **Ổ đĩa** | ~300 MB trống |
| **Mạng** | Cần Internet để tải, đăng nhập và đồng bộ. Các tính năng cốt lõi vẫn chạy offline. |

---

## 2. Tải file cài đặt

| Hệ điều hành | Link tải | Phiên bản |
| --- | --- | --- |
| Windows | **https://mydesk.vn/tai-ve?p=win** | v1.3.121 (~88.9 MB) |
| macOS | https://mydesk.vn/#download | Đang phát hành |

Bạn cũng có thể vào trang chủ **https://mydesk.vn/** và bấm nút **Tải miễn phí** ở đầu trang.

---

## 3. Cài đặt trên Windows

1. Mở file `.exe` vừa tải xuống (thường nằm trong thư mục **Downloads**).
2. Nếu Windows hiện màn hình xanh — xem [mục 4](#4-gặp-màn-hình-xanh-của-windows-smartscreen) ngay dưới.
3. Chờ trình cài đặt chạy xong (khoảng **30 giây**).
4. MyDesk tự mở. Bạn có thể dùng ngay, hoặc đăng nhập nếu muốn đồng bộ dữ liệu giữa nhiều máy.

---

## 4. Gặp màn hình xanh của Windows (SmartScreen)

Khi mở file cài, Windows có thể hiện thông báo:

> **Windows đã bảo vệ PC của bạn**
> Microsoft Defender SmartScreen đã ngăn một ứng dụng không xác định khởi động…

Đây **không phải lỗi** và cũng không có nghĩa file có vấn đề. Windows hỏi thêm một bước với những ứng dụng còn mới, chưa đủ lượt cài để hệ thống tự nhận diện nhà phát hành.

**Cách xử lý:**

1. Bấm **Thông tin thêm** — *máy tiếng Anh: **More info*** — dòng chữ nhỏ ngay dưới đoạn mô tả.
2. Bấm tiếp **Vẫn chạy** — *máy tiếng Anh: **Run anyway***.
3. Quá trình cài đặt bắt đầu như bình thường.

---

## 5. Cài đặt trên macOS

1. Mở file `.dmg` vừa tải xuống.
2. Kéo icon **MyDesk** vào thư mục **Applications**.
3. Mở MyDesk từ Launchpad. Lần đầu, nếu macOS báo không xác minh được nhà phát hành: vào **System Settings → Privacy & Security**, cuộn xuống và bấm **Open Anyway**.

---

## 6. Cập nhật phiên bản

MyDesk ra bản mới gần như mỗi tuần và **tự cập nhật** trong nền:

- Không cần tải lại file cài đặt.
- Toàn bộ công việc, ghi chú, thống kê và bố cục bàn làm việc được giữ nguyên.
- Muốn kiểm tra thủ công: mở **Cài đặt → Về MyDesk → Kiểm tra cập nhật**.

---

## 7. Gỡ cài đặt

- **Windows:** *Settings → Apps → Installed apps* → tìm **MyDesk** → **Uninstall**.
- **macOS:** kéo **MyDesk** từ thư mục **Applications** vào **Trash**.

Dữ liệu cục bộ không bị xoá cùng ứng dụng. Nếu muốn xoá sạch, hãy sao lưu trước rồi xoá thư mục dữ liệu của MyDesk trong `%APPDATA%` (Windows) hoặc `~/Library/Application Support` (macOS).
